Overview

Built to solve a real problem: monitoring dozens of job boards for highly specific GenAI security roles in financial services across Florida. Rather than manually searching weekly, this agent runs autonomously every Monday — scraping listings, filtering by keyword relevance, scoring with AI, and delivering a prioritized digest.

The system supports multiple user profiles with independent search criteria, keyword tiers, and geographic preferences. Each profile gets personalized scoring and notifications. Designed for a family of users with completely different job search parameters.

Tech Stack

Compute

AWS Lambda (Python 3.12) with SAM for infrastructure as code. EventBridge for cron scheduling. Deployed via CloudFormation.

Data

DynamoDB single-table design with GSI for status-based queries. TTL for automatic 90-day cleanup. PAY_PER_REQUEST billing.

Security

API keys in Secrets Manager. IAM least-privilege per Lambda. DynamoDB encryption at rest. No secrets in environment variables.

AI / ML

Amazon Bedrock with Claude Sonnet for intelligent job scoring. Structured JSON output. Cost-capped at $5/month for Bedrock calls.

DynamoDB Design

Single-Table, Multiple Entity Types

Profiles, job listings, and configuration all live in one table — differentiated by key structure following DynamoDB best practices. This eliminates cross-table joins and simplifies IAM permissions.

Primary Keys

PK: SOURCE#google_jobs | PROFILE#chris
SK: JOB#abc123 | CONFIG
Enables direct lookups and source-based queries.

GSI1 — Status Index

GSI1PK: STATUS#new | STATUS#scored
GSI1SK: DATE#2026-02-15
Powers the scorer Lambda: "get all new listings, newest first."

Security Decisions

🔐
Secrets Manager over environment variables. API keys are retrieved at runtime via boto3, never stored in Lambda configuration. Supports rotation without redeployment.
🛡️
Least-privilege IAM. Each Lambda gets its own role scoped to only the resources it needs. Scraper can read/write DynamoDB and read Secrets Manager — nothing else.
🔒
DynamoDB encryption at rest. AWS-managed keys (SSE-S3) enabled by default. All data encrypted transparently.
🧹
TTL-based data lifecycle. Job listings auto-expire after 90 days. No manual cleanup needed, no stale data accumulation.
📋
Structured JSON logging. All Lambda output uses JSON format for CloudWatch integration. Enables metric filters and correlation across the pipeline.

Intelligent Filtering

Three-Tier Keyword Scoring

Before listings ever reach Bedrock (which costs money per call), a pre-filter scores them based on keyword relevance. This reduces Bedrock API costs by 60-70% by eliminating clearly irrelevant listings at the scrape stage.

Tier 1 — Must Match (10pts each)

Core role keywords: generative AI, GenAI, LLM, AI security, Bedrock, AI governance. Must match ≥2 or listing is discarded.

Tier 2 — Boost (5pts each)

Industry & seniority: financial services, banking, security architect, principal. Increases score but not required.

Geographic Match (15pts)

Target locations: Miami-Dade, Broward, Palm Beach, Brevard County, Space Coast, or Remote.
